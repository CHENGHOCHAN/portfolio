# 莊河泉｜遊戲企劃作品集

2026 年畢業於國立虎尾科技大學多媒體設計系，求職方向為**遊戲企劃、系統設計與關卡設計**。我將玩家需求整理成規則、流程、規格文件與驗收條件，再透過引擎原型和測試回饋持續修正；世界構築是串連玩法、空間與敘事的設計特色。

## 精選案例

### 巨人與孤獨星球

UE5 團隊畢業製作。個人擔任**企劃主責與專案統籌**，交付世界觀與玩法企劃、關卡流程、UI 需求、提報文件、PV 與展場版本。

- [三個設計判斷](https://chenghochan.github.io/portfolio/giants.html#decision-cases)
- [60 秒規格：無 HUD 關卡引導](https://chenghochan.github.io/portfolio/#specs)
- [YouTube 實機影片](https://youtu.be/J6V5wPnu3lI)
- 測試現況：完成 3 個公開展覽場域展示；早期未留存測試人數與完成率，下一輪將記錄錯路率、抵達時間與機關完成率。

### Soul of Another World

Unity 團隊動作 RPG 原型。個人擔任**企劃主責**，交付格擋與反擊循環、精力規則、Boss 三階段、道具功能與 UI 資訊規格。

- [三個設計判斷](https://chenghochan.github.io/portfolio/soul.html#decision-cases)
- [60 秒規格：格擋與反擊循環](https://chenghochan.github.io/portfolio/#specs)
- [YouTube 實機影片](https://youtu.be/I7djSups4bo)
- 測試現況：完成 6 人團隊內部驗證；外部測試與完成率仍待補測。

### Tiny Factory

Godot 4 手機分揀解謎原型。完成 10 關、自動驗證與 Android APK；外部玩家測試仍待執行。

- [專案規格與測試紀錄](https://chenghochan.github.io/portfolio/tiny-factory.html)
- [下載 Android APK](https://chenghochan.github.io/portfolio/downloads/TinyFactory-Android-Demo.apk)

## 工作方法與工具

Google Sheets / Excel、Word / PowerPoint、流程圖與 Wireframe、Notion、Unreal Engine 5、Unity、Godot、Git / GitHub。Blender、Photoshop、Premiere Pro 與 After Effects 作為素材檢查、整合與展示支援工具。

## 團隊素材標示

作品頁以「個人負責／團隊共同完成／協作者製作」標示素材權責。角色原畫、場景美術與建模不會被誤列為個人創作；個人貢獻集中於企劃、系統與關卡規格、UI 資訊、專案統籌及成果展示。
