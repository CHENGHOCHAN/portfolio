DESIGN DECISIONS · 3 CASES

三個從問題走到結果的設計判斷

先閱讀我做了什麼判斷，再向下查看 155 份角色、場景、機關與 UI 原始素材。

無 HUD 仍要讓玩家知道往哪走

問題
取消大量任務提示後，玩家可能在遼闊場景失去方向。
決策
讓地標、光源、高度差與傳送門共同承擔導航。
實作
以遠景遺跡建立方向，再用道路、跳板與壓力板串接主要路線。
結果
完成可實機演示的關卡流程；下一輪將量測錯路率與抵達時間。

巨大尺度不能只是一張漂亮背景

問題
巨人若只負責視覺壓迫，與實際玩法會脫節。
決策
把巨人定位成需要閱讀與規避的移動威脅，而非純粹血量目標。
實作
以約 10：1 尺度、攻擊窗口、地形遮蔽、跑酷與大炮機關建立反制空間。
結果
巨人遭遇、機關解謎與逃脫被整合進同一段實機節奏。

長期團隊製作容易失去共同版本

問題
企劃、美術、建模與引擎內容跨越多個階段，資訊容易分散。
決策
用提報節點、文件與素材歸檔建立可追溯的版本目標。
實作
依角色、巨人、場景、機關、UI 與實機成果整理交付與展示順序。
結果
完成畢業製作、3 個展覽場域展示與 155 項設計素材歸檔。

SYSTEM ANALYSIS · 企劃設計

觀察地形，而不是正面硬碰

《巨人與孤獨星球》把巨大敵人的壓迫感轉化成路線判斷。玩家要閱讀地形、機關與巨人行為，找出能逃脫或反制的路徑，而不是只靠連續攻擊解決問題。

DESIGN THESIS在舒適明亮的自然景色中，讓孤身旅行者面對 10：1 尺度的泰坦巨人；孤獨不只來自荒涼，也來自世界過於遼闊而只剩自己前進。
01探索遺跡

閱讀道路、地標與傳送門位置。

02辨識威脅

觀察巨人、陷阱與高度差。

03啟動機關

運用跳板、壓力板與大炮。

04逃脫或反制

選擇跑酷路線並規避傷害。

05前往下一區

用傳送寶石解鎖新的遺跡。

SYSTEM 01 · SCALE

巨人尺度與威脅閱讀

泰坦巨人是資源戰爭遺留的自動化兵器。巨人與主角約 10：1 的比例，讓玩家先感受到壓迫，再從動作與場地尋找安全窗口。

泰坦巨人10：1 比例地形判讀
SYSTEM 02 · TRAVERSAL

機關解謎與垂直移動

彈跳板是最重要的移動機關，配合充能壓力板、大炮壓力板、尖刺與跑酷平台，把解謎、移動和逃脫整合成同一段流程。

Jump Pad壓力板陷阱跑酷平台
SYSTEM 03 · WORLD

傳送寶石與世界導航

旅行者幼年取得傳送寶石，因而能解鎖星球各地的傳送門。它同時是劇情道具與導航權限，引導玩家前往最終目的地「四季浮島」。

旅行者傳送寶石四季浮島
SYSTEM 04 · IMMERSION

動態環境與材質音效

風向循環掃動讓草地與樹林產生自然擺動；走路、跑步、翻滾與劈砍則依地面或碰撞材質提供不同聲音，補足世界的觸感。
